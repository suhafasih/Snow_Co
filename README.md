# Snow_Co.
Team members- Zoha, Suha, Seline, Zainab, Ilakkiyan
We are creating an interactive book catalogue that allows users to explore and engage with a collection of books. The online library will serve as a digital platform where users can borrow both physical and digital books throiugh a single, integrated catalogue system. The platform is designed to provide quick access to titles while also helping users discover new content and interact with the system.
